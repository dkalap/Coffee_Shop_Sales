# ☕ Coffee Shop Sales Analysis  
A Data Analytics Project
-----
## 📌 Project Overview
This project analyzes sales data from a coffee shop to uncover insights about customer behavior, sales trends, peak hours, product performance, and operational efficiency.  
The goal is to help the business make data-driven decisions to improve revenue, staffing, and product strategy.
-----

## 🎯 Project Objectives
- Understand how sales vary by **day of the week** and **hour of the day**  
- Identify **peak sales hours** and high-traffic periods  
- Calculate **monthly revenue trends**  
- Compare performance across **store locations**  
- Determine **best-selling products** by quantity & revenue  
- Analyze sales by **product categories**  
- Calculate **average order price per customer**  
- Provide actionable insights to improve store performance  

-----
## 🛠 Tools & Technologies Used
- **Excel** → Cleaning, Pivot Tables, Dashboards  
- **Power BI / Tableau (optional)** → Visualizations  
- **Python (optional)** → Pandas for data cleaning & analysis  

---

## 🔍 Steps Performed in the Project

### **1️⃣ Data Cleaning**
- Removed duplicates  
- Formatted date & time columns  
- Calculated new columns (Hour, Day Name, Month Name)  
- Handled missing product categories / prices  
- Standardized labels and categories
